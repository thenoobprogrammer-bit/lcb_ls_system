# LCB Lights and Sound Rental System

PHP + MySQL starter project for:

- Role-based authentication
- Inventory management with image upload
- Payroll management
- Packages and approvals
- Event booking and scheduling
- Payment tracking and printable invoices
- Notifications, messages, reports, and activity logs

## Setup

1. Create a MySQL database by importing [sql/schema.sql](/E:/WEBSYSTEMS/Inventory_Rental_Payroll_System/sql/schema.sql).
2. Update database credentials in [config/app.php](/E:/WEBSYSTEMS/Inventory_Rental_Payroll_System/config/app.php).
3. Place the project in your web root, or adjust `BASE_URL` in [config/app.php](/E:/WEBSYSTEMS/Inventory_Rental_Payroll_System/config/app.php).
4. Open [index.php](/E:/WEBSYSTEMS/Inventory_Rental_Payroll_System/index.php).
